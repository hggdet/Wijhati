# وجهتي — Wijhati

تطبيق خرائط iOS أصلي بـ SwiftUI وApple MapKit، بواجهة عربية كاملة (RTL) ودعم الإنجليزية والكردية. يستخدم عارض خرائط Apple الأصلي مع إسناد Apple المدمج، ويستهدف iOS 17 أو أحدث.

## الميزات
- خرائط Apple القياسية والهادئة والقمر الصناعي والهجينة، مع تضاريس واقعية ثلاثية الأبعاد على iOS 17+
- بحث عالمي مع اقتراحات فورية، وفئات أماكن قريبة
- مسارات بديلة وتوقفات متعددة وأنماط قيادة/مشي/دراجة
- دبابيس للأماكن والطبقات المجتمعية والرسمية، وخطوط للمسارات والرحلات
- متابعة الموقع والتحكم بالكاميرا والإمالة والاتجاه، مع استعادة الخريطة بعد العودة من الخلفية
- بطاقة مكان غنية: مسافة وطقس حي وشروق/غروب واتصال ومشاركة وحفظ ومفضلة
- ملاحة صوتية عربية محلية دون مفتاح، وخيارات صوت سحابي اختيارية
- ملاحة مشي بالكاميرا، وتسجيل رحلات وتصدير GPX
- طبقات وبيانات الطقس ومناطق الوصول ومخطط ارتفاع المسار حيثما تدعمها خدمات التطبيق
- أماكن محفوظة، ودجت، وواجهة عربية RTL مع دعم الإنجليزية والكردية

## الخرائط دون اتصال
لا يتيح MapKit تنزيل أو إدارة مناطق خرائط Apple من داخل التطبيق. تُدار خرائط Apple غير المتصلة من تطبيق خرائط Apple والنظام. البحث وحساب المسارات والطقس في وجهتي ما زالت تعتمد على خدماتها الشبكية الخاصة.

## البناء
GitHub Actions يبني IPA غير موقّع عند كل دفع إلى `main`. وقّعه بمتجرك (iStore) وثبّته.

## البنية
- `App/MapBridge.swift` — جسر Apple MapKit (دبابيس، خطوط مسارات ورحلات، تحكم بالكاميرا واستعادة دورة الحياة)
- `App/GeoService.swift` — البحث والأماكن والمسارات والطقس والارتفاعات عبر مزودي الخدمات
- `App/ContentView.swift` — الواجهة كاملة
- `App/Models.swift` — النماذج والمخازن (أماكن، رحلات)
