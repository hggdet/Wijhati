# وجهتي — Wijhati

تطبيق خرائط iOS أصلي (SwiftUI + MapKit) بتصميم Liquid Glass وواجهة عربية كاملة (RTL).

## الميزات (الإصدار الأول)
- خريطة Apple Maps تفاعلية بملء الشاشة مع أنماط: قياسي / هجين / قمر صناعي
- بحث مع إكمال تلقائي فوري وبحث نصي
- تصنيفات أماكن قريبة: مطاعم، كافيهات، فنادق، مستشفيات، صيدليات، وقود، حدائق، تسوق
- مسارات مع بدائل متعددة ومقارنة وقت/مسافة، ووسائل: قيادة / مشي / دراجة
- حفظ الأماكن والمفضلة (تُحفظ على الجهاز)
- بطاقة مكان: عنوان، مسافة، هاتف واتصال، مشاركة
- ملاحة حية + **ملاحة بالجيب**: إرشاد صوتي بالعربية واهتزاز عند المنعطفات، شاشة داكنة موفرة للبطارية
- بوصلة وموقع مباشر

## بناء الـ IPA (غير موقّع)
1. ادفع أي تغيير إلى فرع `main` أو شغّل Workflow يدوياً من تبويب **Actions** → *Build unsigned IPA* → *Run workflow*.
2. بعد نجاح البناء، حمّل **Wijhati-unsigned-IPA** من Artifacts في صفحة التشغيل.
3. وقّع ملف `Wijhati-unsigned.ipa` بمتجرك الخاص (iStore) وثبّته على جهازك.

## التطوير المحلي
يتطلب المشروع [XcodeGen](https://github.com/yonaskolb/XcodeGen):
```bash
brew install xcodegen
xcodegen generate
open Wijhati.xcodeproj
```
- الحد الأدنى: iOS 17 — وواجهة Liquid Glass الحقيقية (`glassEffect`) تُفعَّل تلقائياً على iOS 26+.
- Bundle ID: `com.hggdet.wijhati`

## خارطة الطريق
- ملاحة منعطف بمنعطف كاملة مع إعادة توجيه تلقائي وتنبيه خروج عن المسار
- مسارات متعددة التوقفات وتسجيل رحلات GPX وتصدير/استيراد الأماكن
- طبقات إضافية: مباني ثلاثية الأبعاد، رادار مطر، منطقة وصول (Isochrone)
- أيقونة التطبيق الرسمية (دبوس W المتدرج) كأصل AppIcon بأحجام المتجر
