# وجهتي — Wijhati

تطبيق خرائط iOS أصلي (SwiftUI + MapLibre / OpenStreetMap) بتصميم Liquid Glass وواجهة عربية كاملة (RTL). الخريطة خاصة بالتطبيق — ليست خرائط آبل.

## الميزات (1.1)
- خريطة OpenStreetMap بمحرك MapLibre مع أنماط: قياسية / فاتحة / قمر صناعي (Esri)
- بحث عالمي عبر Photon (OSM) مع اقتراحات فورية أثناء الكتابة
- تصنيفات قريبة عبر Overpass: مطاعم، كافيهات، فنادق، مستشفيات، صيدليات، وقود، حدائق، تسوق
- مسارات OSRM ببدائل + توقفات متعددة (أضف أي مكان كتوقف) + وسائل: قيادة / مشي / دراجة
- بطاقة مكان غنية: مسافة، طقس حي وشروق/غروب (Open-Meteo)، اتصال، مشاركة، حفظ ومفضلة
- ملاحة بالجيب: إرشاد صوتي عربي + اهتزاز بدون شاشة
- تسجيل رحلات حي (مسافة/مدة/سرعة) وتصدير GPX + قائمة رحلات
- طبقات: أبنية ثلاثية الأبعاد، رادار مطر حي (RainViewer)، منطقة وصول 10/20/30 دقيقة (Valhalla)
- مخطط ارتفاع للمسار (Open-Meteo Elevation)
- أماكن محفوظة مع تصدير JSON
- أيقونة التطبيق الرسمية (W) مضمّنة — تُفكّ من icon-1024.png.b64 أثناء البناء

## البناء
GitHub Actions يبني IPA غير موقّع عند كل دفع إلى main. وقّعه بمتجرك (iStore) وثبّته.

## البنية
- `App/MapBridge.swift` — جسر MapLibre (دبابيس، خطوط مسار/رحلة، منطقة وصول، أبنية 3D، رادار)
- `App/GeoService.swift` — Photon / Overpass / OSRM / Valhalla / Open-Meteo / RainViewer
- `App/ContentView.swift` — الواجهة كاملة
- `App/Models.swift` — النماذج والمخازن (أماكن، رحلات)
